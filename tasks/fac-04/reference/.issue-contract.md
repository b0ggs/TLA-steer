# Issue FAC04: add a `json` output subcommand to tocsmith (release 1.2.0)

tocsmith 1.1.0 only emits Markdown tables of contents. Release 1.2.0 adds a
`json` subcommand that emits the table of contents as a JSON document, plus
the release chores that go with it (docs example, changelog, defaults note,
test, version bump, and an empty-input fix in the scanner).

Acceptance notes tagged FAC04-* appear in README.md, docs/cli.md,
CHANGELOG.md, examples/; all are in scope.

Grading: requirement key Rn corresponds to acceptance note FAC04-n
(R1 from FAC04-1 through R10 from FAC04-10). Regression keys:

- G1 — `python -m tocsmith generate examples/sample.md` still prints exactly
  the content of `examples/sample-toc.md` and exits 0.
- G2 — the existing suite still passes:
  `python -m unittest discover -s tests -p "test_core_*.py"` from the
  project root.
