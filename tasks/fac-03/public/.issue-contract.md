# Issue contract: datespan 0.4.1 maintenance release

## Reported bug

Users report that every range loses its final day. Running
`python -m datespan expand 2026-03-01..2026-03-03` prints only `2026-03-01`
and `2026-03-02`; the end date of the range never appears. Fix
`expand_range` in `datespan/ranges.py` so that a range is inclusive of its
end date.

## Scope

This release is scored against tagged acceptance notes, not only the bug
report above. Acceptance notes tagged FAC03-* appear in README.md,
docs/behavior.md, CHANGELOG.md, and tests/test_ranges.py; all are in scope.
Complete every FAC03-* note (FAC03-1 through FAC03-10) as part of this
release.

Previously working behavior documented under "Stable behavior (do not
break)" in README.md must keep working.
