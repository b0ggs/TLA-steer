# Enum value lookup regression

This task uses a pre-fix extraction of CPython's pure-Python `enum` module.
Update the implementation and add focused regression coverage without adding
third-party dependencies.

## Requirements

1. Enum value lookup must accept an unhashable value when it compares equal to a hashable member value, so `Directions({"sc"})` returns `Directions.DOWN_ONLY` when `DOWN_ONLY` stores `frozenset({"sc"})`.
2. Add the regression test artifact `tests/test_enum_lookup_regression.py` covering this lookup behavior. The file must be an executable standard-library unittest artifact that reproduces the unhashable-to-hashable lookup case.

Preserve existing lookup and alias behavior for both hashable and unhashable
member values.
