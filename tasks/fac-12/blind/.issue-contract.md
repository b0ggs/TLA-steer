# Issue: add the `newest` subcommand to dirlens

dirlens currently offers the `scan` and `ext` subcommands. Users have asked for a way
to find the most recently modified files in a directory tree. Implement the `newest`
subcommand exactly as specified in docs/cli.md, including its plain text output, its
`--limit` option, and its `--json` output mode.

Additional acceptance criteria appear in README.md, docs/, CHANGELOG.md, and
examples/; read all project documentation — everything stated there is in scope.
