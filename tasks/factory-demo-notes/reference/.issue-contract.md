# Notes search and export

Extend the in-memory `Notes` library in `notes.py` with tag-filtered text search and deterministic JSON export. Preserve the existing `add`, `get`, and `all` behavior described by the code and supporting documentation.

Notes.search must accept optional query and tags arguments, both defaulting to no filtering, and return every note when called with no arguments.

Notes.export_json must return a JSON string representing an object with schema_version equal to 1 and a notes array.

The detailed behavior is intentionally kept near the relevant topic:

- `docs/search.md` defines matching.
- `docs/results.md` defines search-result behavior.
- `docs/export.md` defines deterministic JSON structure.
- `docs/encoding.md` defines text encoding and termination.

Use only the Python standard library.
