# Issue: add a `stats` subcommand to wordfreq

wordfreq currently offers `count` and `top`. Users keep asking for a quick
one-screen summary instead of a full table, so this release adds a `stats`
subcommand that reports the total word count, the number of distinct words,
and the most frequent word, with a `--min-length` filter.

The full specification of the subcommand — its output format, its option and
default, its help text, and its exit-status behavior — is written out in
`docs/cli.md` under "stats (being added in this release)". Implement it
exactly as specified there.

Additional acceptance criteria appear in README.md, docs/, CHANGELOG.md, and
examples/; read all project documentation — everything stated there is in
scope. Existing behavior (the `count` and `top` subcommands and the current
test suite) must keep working.
