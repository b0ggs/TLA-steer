# Issue: negation patterns never re-include paths

`Sieve.decide` stops at the first matching rule and treats every match
as an exclusion, so a later `!pattern` can never rescue a path that an
earlier pattern excluded. Negation is effectively dead code.

Reproduction:

```python
from pathsieve import Sieve

s = Sieve(["build", "!keep.txt"])
s.excludes("build/keep.txt")    # returns True today, must return False
s.excludes("build/other.txt")   # must remain True
```

Expected behaviour: rules are evaluated in order and the last matching
rule wins; when that last matching rule is a negation the path is
included, otherwise it is excluded. Paths matching no rule at all stay
included.
