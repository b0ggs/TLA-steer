# Issue: add a `summarize` subcommand to recval

recval currently reports validation problems one line at a time via the
`validate` subcommand. Downstream tooling wants machine-readable counts
instead of grep-able text. Add a `summarize` subcommand that validates
every record in a JSON Lines file and prints a single JSON summary
object, and finish the release chores that go with it.

Acceptance notes tagged FAC06-* appear in README.md, docs/cli.md,
CHANGELOG.md, examples/; all are in scope.

Keep the existing `validate` and `rules` subcommands working exactly as
documented in docs/cli.md.
