# Reject dotted-key namespace redefinitions

Tomli currently accepts dotted keys that define values below namespaces which
were already created by table or array-of-tables syntax. Update the parser and
add a focused standard-library regression test. Preserve valid dotted-key and
table parsing behavior, and do not add dependencies.

The deliverables are:

1. The parser must raise `tomli.TOMLDecodeError` when a dotted key inside a reopened table attempts to define a value below a table that was already explicitly created.
2. The parser must raise `tomli.TOMLDecodeError` when a dotted key inside a reopened table attempts to define a value below an array-of-tables namespace that was already created.
3. Add a standard-library unittest regression artifact at `tests/test_dotted_keys_regression.py` that covers both invalid namespace-extension forms.
