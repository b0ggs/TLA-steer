# Issue: add a `prune` subcommand to logrotor

logrotor 1.3.0 can rotate logs (`rotate`) and list archives (`list`),
but old archives accumulate forever. Add a `prune` subcommand that
deletes old archives while keeping the newest N per log, together with
the release chores that go with it (docs, changelog entry, version
bump, example transcript, tests).

Acceptance notes tagged FAC05-* appear in README.md, docs/cli.md,
CHANGELOG.md, examples/; all are in scope.

Start with the "Planned subcommand: `prune`" section of `docs/cli.md`
(FAC05-1 through FAC05-5), then sweep `README.md` (FAC05-6, FAC05-9),
`CHANGELOG.md` (FAC05-7), and `examples/README.md` (FAC05-8) for the
remaining notes. Everything stays Python standard library only.
