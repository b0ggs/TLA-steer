# Doctest exception-note comparison regression

This task uses a pre-fix extraction of CPython's pure-Python `doctest` module.
Update the implementation and add focused regression coverage without adding
third-party dependencies.

## Requirements

1. Doctest exception comparison must include every exception note after the exception message, while SyntaxError-family comparisons must ignore source-location decoration but still compare the exception message and notes.
2. Add the regression test artifact `tests/test_doctest_notes_regression.py` covering ordinary exceptions, multiple notes, and SyntaxError-family notes. The file must be an executable standard-library unittest artifact that demonstrates the corrected comparisons.

Incorrect expected notes must continue to fail comparison, and ordinary
doctests without exception notes must retain their existing behavior.
