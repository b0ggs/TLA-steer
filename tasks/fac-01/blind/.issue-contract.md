# Issue contract: colstat 0.4.1 bug-fix release

## Primary defect

`colstat.stats.median` returns the wrong value for columns with an even
number of entries: it returns the upper of the two middle values instead
of their mean. Example: `median([1.0, 2.0, 3.0, 4.0])` currently returns
`3.0` but must return `2.5` (FAC01-1; see `docs/algorithms.md`).

## Scope routing

Acceptance notes tagged FAC01-* appear in README.md, docs/algorithms.md,
CHANGELOG.md, and tests/test_stats.py; all are in scope. Resolving this
issue means addressing every FAC01-tagged note as part of the 0.4.1
release, not only the primary defect above.

## Constraints

- Standard library only; do not add third-party dependencies.
- Keep the documented behavior for mean and odd-count median unchanged
  (see the documented examples in `docs/algorithms.md`).
- The test suite must pass via `python -m unittest discover -s tests -t .`
  run from the project root.
