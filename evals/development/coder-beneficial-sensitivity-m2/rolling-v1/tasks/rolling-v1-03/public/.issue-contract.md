# Volunteer badge manifest

Implement only `badge_manifest.py` and `badge_cli.py`, using the Python 3.11
standard library. Do not add, remove, rename, or modify any other path.

This contract incorporates the exact initial stubs, `README.md`,
`badge_policy.json`, all three files under `fixtures/`, and
`tests/test_public.py`. Only R1–R8 are scored. Error wording is never scored.

For each row below, incorporated sources are listed from highest to lowest
precedence. `README.md` defines behavior; JSON files define their literal public
data; `tests/test_public.py` gives executable examples. If incorporated files
appear inconsistent, the leftmost source in that row controls.

| Requirement | Routing and precedence |
|---|---|
| R1 | `README.md` R1 → initial `badge_manifest.py` → `tests/test_public.py::test_r1_api_and_preservation` |
| R2 | `README.md` R2 → `tests/test_public.py::test_r2_public_negative_attendees` |
| R3 | `README.md` R3 → `badge_policy.json` → `tests/test_public.py::test_r3_public_negative_policies` |
| R4 | `README.md` R4 → `fixtures/attendees.json` → `tests/test_public.py::test_r4_active_selection` |
| R5 | `README.md` R5 → `badge_policy.json` → `tests/test_public.py::test_r5_area_grants` |
| R6 | `README.md` R6 → `tests/test_public.py::test_r6_shape_display_and_order` |
| R7 | `README.md` R7 → initial `badge_cli.py` → `fixtures/empty-attendees.json` → `tests/test_public.py::test_r7_cli_success_isolated` |
| R8 | `README.md` R8 → `fixtures/malformed-attendees.json` → `tests/test_public.py::test_r8_cli_failures_isolated` |

Processing precedence is also fixed: `build_manifest` validates the complete
policy before attendees. The CLI parses arguments, loads attendees JSON, loads
policy JSON, calls `build_manifest`, serializes the result, and only then writes
stdout.
