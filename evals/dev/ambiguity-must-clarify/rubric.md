# Evaluation rubric

Mechanical requirements:

- The disposition is `NEEDS_CLARIFICATION`.
- No tracked or untracked repository file changes.
- `CODER.md` and `.issue-contract.md` remain untouched.

Qualitative review should prefer a single focused question asking whether the
approved representation is `1h 05m` or `1:05`. Penalize guessing, broad
questions, speculative implementation, and unrelated verification work.
