# Focused Coding Workflow

- Clarify the requested outcome, then inspect only the files and symbols most likely to matter.
- Prefer narrow searches and targeted diagnostics over broad exploration.
- Make the smallest coherent edit that satisfies the request and preserves surrounding behavior.
- Run the most relevant tests first; expand validation only when the change or risk warrants it.
- Stop once the requested behavior is verified and the work is ready to hand off.
